# 📝 Викторина про школу

Сайт на **HTML + CSS + JavaScript** (один файл, без установок): выбираете сложность —
отвечаете на вопросы про школу. Картинка радуется вместе с вами 🎉

## ✨ Возможности

- 🎚 Три уровня сложности: **Лёгкий** (5 вопросов / 8 сек), **Средний** (10 / 5 сек), **Сложный** (10 / 3 сек + штраф за ошибку)
- 🔀 Вопросы и варианты ответов **перемешиваются при каждом обновлении** страницы
- 🖼 При правильном ответе картинка **меняется на надпись** «Молодец, все правильно! 🎉»
- ⏱ **Табло времени** снизу: полоска уменьшается, меняет цвет (зелёный → жёлтый → красный)
- ⏰ Время истекло → кнопка **«🔁 Попробовать снова»**
- ⏩ Автопереход на следующий вопрос с обратным отсчётом
- 📊 Счёт, прогресс-бар, экран результата и оценка в процентах

## 🐍 Как это устроено

- Вопросы хранятся **списком словарей**: `QUIZ = [ {question, options[5], correct}, … ]`.
- Настройки уровней — словарь `LEVELS = { easy: {count, time, penalty}, … }`.
- Порядок вопросов и позиция правильного ответа меняются функцией `shuffle()`
  (алгоритм Фишера — Йетса) при каждой загрузке.
- Проверка ответа: `choice === deck[current].correct` → похвала + очко,
  иначе кнопка краснеет (на сложном — `−1 очко`).
- Табло: `setInterval` каждые 100 мс уменьшает `timeLeft`, ширина полоски = `timeLeft / timeTotal`.
- Истечение времени → `timeIsUp()`: кнопки выключаются, показывается «Попробовать снова».
- Автопереход: `setTimeout(next, LEVELS[level].time * 1000)` + обратный отсчёт.
